# 🎨 Pigment Demand Studio

A full-stack product management system with ARIMA-based demand forecasting.

## 🚀 Features
- Customer shade exploration UI
- Admin dashboard
- Demand prediction using ARIMA
- PDF report generation
- Inventory insights

## 🧠 Tech Stack
- Frontend: React (Vite)
- Backend: FastAPI
- ML Model: ARIMA (statsmodels)
- Database: SQLite

## ▶️ Run Project

### Backend
uvicorn app:app --reload

### Frontend
npm run dev
